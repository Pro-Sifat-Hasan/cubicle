# Code of Conduct

Cubicle follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep discussions about the work.
Harassment, discrimination, and personal attacks are not tolerated.

To report unacceptable behaviour, contact the maintainers privately through
[GitHub Security Advisories](https://github.com/Pro-Sifat-Hasan/cubicle/security/advisories/new)
or by email to the repository owner. All reports are handled confidentially.
